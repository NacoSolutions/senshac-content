# Writing Documentation

Use this skill when adding repository guidance for Senshac editorial content.

## Workflow

- State the intended content or workflow outcome before editing.
- Use concise headings, imperative verbs, and affirmative instructions.
- Name TinaCMS, localization, export, and review commands precisely when they apply.
- Link related repository guidance with relative paths.
- Keep documentation changes separate from editorial fixtures, schemas, and application code.

## Acceptance checks

- Each instruction names an action and its expected outcome.
- Commands are copyable and scoped to the content workflow.
- Links resolve to files in this repository.
- The final diff contains only the requested documentation and configuration paths.
